# Reference data — not page content

## kbp_store_master.json

262 KFC restaurants from
`2015 KFC ASAP Pilot Restaurants Kulp - ALL KBP Surveyed Stores.xlsx`,
attached to a June 2017 email from Tony Miceli of KBP Foods.

### What it is for

Resolving store numbers. The crew wrote `KFC(356)` in photo-email subjects;
this file says that is `G135356`, 8939 W 7 Mile Rd, Detroit MI. All nine stores
named in the photo emails resolve against it, and it supplies a street number
for one the email left incomplete.

### What it is NOT for

**Publishing.** This is a client's own list of their restaurant locations — the
whole estate they asked to be surveyed and bid, most of it work this company
never did. Putting 262 KBP addresses on a public website would publish a
customer's confidential property schedule, and would also imply a body of work
the documents do not support: 246 of the 262 are marked "Not Started".

Only stores with independent completion evidence — a punch list, an
after-photograph, an invoice — may appear on a page. See
`src/data/georgiaStores.js` and `src/data/carolinaProgram.js` for the grading.
